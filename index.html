The Roadmap

What You'll Learn

Five foundational areas that every beginner should cover before diving into specialized topics like ethical hacking or cloud security.

01 — Network Fundamentals

How the Internet Works

IP addresses, DNS, routers, TCP/UDP, HTTP — the plumbing of the internet.
02 — Operating System Basics

Files, Processes & Permissions

Understand how your computer manages programs and who is allowed to do what.
03 — Linux Essentials

The Hacker's Operating System

Navigate the terminal, manage files and permissions, and write basic scripts.
04 — Python Essentials

Automate Everything

Write simple scripts to automate tasks — the skill that separates good from great.
05 — Info Security Fundamentals

CIA Triad & Common Attacks

Understand what security actually means before you try to break or defend anything.
