Step-by-Step

The Beginner Roadmap

Five foundational topics, in the order you should learn them. Click any section to expand it and see what to study.

01

Network Fundamentals

How data travels across the internet
▼

Before you can learn to attack or defend a network, you need to understand how networks work. Think of networking as learning the "rules of the road" before you drive — everything in cybersecurity depends on this foundation.

Why It Matters for Cybersecurity

Nearly every cyberattack happens over a network. Hackers exploit protocols, intercept traffic, and abuse how devices communicate. If you understand how data moves, you can understand how it gets stolen — and how to stop it.

Key Concepts to Learn
IP Addresses DNS Routers & Switches TCP vs UDP HTTP & HTTPS Ports & Protocols OSI Model (7 layers) Packets & Firewalls
→

Next Step: Download Wireshark (free) and capture real network traffic on your own computer. Seeing actual packets makes these concepts click instantly. Also check out Professor Messer's free CompTIA Network+ videos on YouTube.

02

Operating System Basics

Files, processes, memory, and permissions
▼

Your operating system is the software that controls everything on your computer — it manages files, runs programs, and decides who is allowed to do what. Understanding how it works is essential before diving into hacking or security tools.

Why It Matters for Cybersecurity

Malware hides in processes. Attackers exploit weak file permissions. Defenders monitor system logs for suspicious activity. Whether you're on Windows or Linux, OS knowledge is the skeleton key that unlocks almost everything else in security.

Key Concepts to Learn
File Systems Processes & Threads Memory Management User Accounts & Groups File Permissions System Logs Command Line Basics Task Manager / Activity Monitor
→

Next Step: Spend time exploring both Windows and Linux. Use the free tool VirtualBox to run a Linux virtual machine on your Windows PC — you can experiment safely without breaking anything.

03

Linux Essentials

Terminal, permissions, Bash, and SSH
▼

Linux is the operating system of the internet. Most web servers run it. Most hacking tools are built for it. Most cybersecurity labs and competitions use it. Getting comfortable in a Linux terminal will open more doors than almost any other skill on this list.

Why It Matters for Cybersecurity

Security tools like Nmap, Metasploit, Burp Suite, and Wireshark work best on Linux. Capture-the-flag (CTF) competitions almost always use Linux environments. Penetration testers and security analysts spend their days in the Linux terminal — learning it early gives you a massive advantage.

Key Concepts to Learn
Terminal Navigation (cd, ls, pwd) File Operations (cp, mv, rm) File Permissions (chmod, chown) Package Managers (apt, yum) Bash Scripting SSH & Remote Access Text Editors (nano, vim) Pipes & Redirects
→

Next Step: Try TryHackMe (free tier) — it has beginner-friendly Linux rooms with a browser-based terminal so you don't even need to install anything. The "Linux Fundamentals" path is perfect for this stage.

04

Python Essentials

Scripting, automation, and simple tools
▼

Python is the most popular language in cybersecurity. It's beginner-friendly, powerful, and used everywhere — from writing your own security tools to automating tedious tasks. You don't need to become a software engineer, but being able to read and write simple Python scripts is a superpower.

Why It Matters for Cybersecurity

Security professionals use Python to automate scans, parse log files, interact with APIs, and build quick proof-of-concept exploits. Even understanding existing Python tools (like many in Kali Linux) requires knowing the basics. It's the language that ties everything together.

Key Concepts to Learn
Variables & Data Types If/Else Logic Loops (for, while) Functions Reading & Writing Files Lists & Dictionaries Importing Libraries Simple Automation Scripts
→

Next Step: Write a simple port scanner in Python using the socket library. It's a classic beginner project that teaches you networking and coding at the same time. Search "Python port scanner tutorial" and build your own version.

05

Information Security Fundamentals

CIA triad, encryption, attacks, and best practices
▼

Before you can hack or defend anything, you need to understand what "security" actually means. This section covers the core principles that every cybersecurity professional — from help desk to CISO — should know by heart.

Why It Matters for Cybersecurity

Security isn't just a technical problem — it's a mindset. Understanding why attacks happen, what attackers want, and how defenses work gives you the mental model to think like both an attacker and a defender. This knowledge makes every other topic on this roadmap make more sense.

Key Concepts to Learn
CIA Triad (Confidentiality, Integrity, Availability) Authentication vs Authorization Encryption Basics Hashing & Passwords Common Attacks (phishing, MITM, DoS) Social Engineering Security Best Practices Threat vs Vulnerability vs Risk
→

Next Step: Read about a real-world data breach (the Target 2013 breach or the LinkedIn password leak are great starting points). Apply the CIA triad to understand what went wrong. Then consider studying for the free CompTIA Security+ certification — it covers all of these fundamentals in depth.

After the Basics

Where Can You Go Next?

Once you've worked through these five areas, you'll have a solid foundation. Here are some directions beginners commonly explore after this roadmap.

🏴‍☠️

Ethical Hacking / Pen Testing

Learn to think like an attacker. Platforms like TryHackMe and HackTheBox offer hands-on hacking practice in safe, legal environments.

🛡️

Blue Team / Defense

Focus on monitoring, detection, and incident response. Look into SIEM tools, log analysis, and the role of a Security Operations Center (SOC) analyst.

📜

Certifications

Entry-level certs like CompTIA Security+, CompTIA Network+, or Google Cybersecurity Certificate are great next steps that employers recognize.
